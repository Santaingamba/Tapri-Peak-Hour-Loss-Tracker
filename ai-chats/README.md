## Export guidance

- Export the actual conversation, not a rewritten summary presented as a transcript.
- Keep enough context to show the prompt, relevant response, and any follow-up corrections.
- Do not include passwords, API keys, session secrets, private database files, or personal customer information.
- If a conversation contains sensitive material, redact it in a copy only if the assignment permits redaction; preserve the original securely.
- Do not claim that an export exists until the file has been added and checked.

This README is an instruction file only. It is not itself an AI conversation export.
